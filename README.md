## 📖 为什么开发 ClashNodeX？(作者心路与痛点背景)

作为一名长期的科学上网重度用户，作者过去习惯使用经典的 **v2rayN** 进行节点管理：随手按 `Ctrl+V` 贴入节点、直接截屏扫二维码、自由把常用节点置顶到最前面、直观测速改名，用起来极其得心应手。

后来转到了 **Clash Verge Rev**，瞬间被其现代精致的图形界面、极低系统资源开销以及强大的规则分流所惊艳。然而，在日常节点维护上，却遇到了巨大落差：
- 朋友临时发来一个节点，在 Clash 里无法直接添加，必须手动打开几千行的 YAML 配置，或者手写 Merge 扩展脚本；
- 订阅更新后节点顺序完全被打乱，无法把自己最常用的节点置顶；
- 手机上能正常连上的 Reality 节点（如部分 VLESS 节点），在 Windows 端由于缺少 uTLS 指纹模拟直接超时连不上；
- 想测速还要经过复杂的链路，无法随心切换测试模式；
- 手动改 YAML 稍有缩进错误，整套配置直接损坏断网。

**Clash 节点跃迁 (ClashNodeX)** 便应运而生：**它不替代 Clash Verge Rev，而是作为其专属的“副驾驶极速管家”，将 Clash 的现代美学与分流实力，同 v2rayN 极致自由的节点管理体验完美融合！**

## ✨ 核心特性深度解析

### 1. 📋 全协议极速导入 (`Ctrl+V`) & 订阅批量拉取
在软件任意界面按下 `Ctrl+V`，自动识别并解析剪贴板内容：
* **前沿协议全面覆盖**：
  * **VLESS**（Reality、Vision、WebSocket、gRPC、TLS 全流控支持）
  * **Hysteria 2** (`hy2://` / `hysteria2://`)
  * **VMess** (AEAD)、**Trojan**、**Shadowsocks (SS)**、**TUIC**
* **订阅智能解析**：直接贴入 `http(s)://` 订阅链接，自动远程拉取并提取所有节点；
* **YAML 片段解析**：支持直接粘贴单段或多段 YAML 节点配置。

### 2. 📷 首创剪贴板截图 & 本地图片二维码一键识别
* **截屏直接导入**：使用 Windows 自带截屏（`Win + Shift + S`）或微信/QQ 截图（`Alt + A`）选中屏幕上的节点二维码后，切回 ClashNodeX 直接按 `Ctrl+V`，程序内置 OpenCV 算法自动从剪贴板图片中提取并解析节点！
* **图片文件扫码**：点击工具栏 **【📷 扫码/图片导入】**，选择电脑上的 PNG/JPG/WebP/BMP 图片，批量识别其中包含的所有节点。

### 3. ⚡ 三模精准延迟测速引擎
针对不同网络环境与诊断需求，提供三种可选测速模式（支持工具栏及编辑弹窗即时切换）：
1. **⚡ 真连接延迟 (HTTP 204)**：
   * 直通 Mihomo 内核命名管道，真正通过代理隧道向外网 (`http://www.gstatic.com/generate_204`) 发起真实请求；
   * 测出的是节点能否真正连通外网以及真实的端到端往返时延（RTT）。
2. **🔌 TCP 握手延迟**：
   * 并发对目标节点 IP/域名和端口发起三次握手，测出本地与服务器直连的网络时延。
3. **🔒 Connect / TLS 握手**：
   * 测试目标节点的 TCP 握手 + TLS 证书协商耗时；
   * **自动关联 SNI 域名**：对于 Reality 节点，自动绑定目标 camouflage servername 校验，判断握手是否正常。

### 4. 🛠️ VLESS Reality 智能指纹注入 (彻底解决 7C/7D 等节点电脑超时暗坑)
* **痛点**：很多用户发现自己的部分 Reality 节点在手机端（Shadowrocket / v2rayNG / Sing-box）连接飞快，但在 Windows 版 Clash Verge 上测试却报超时或连接被重置。
* **原因**：移动端客户端默认会自动模拟 Chrome 的 uTLS ClientHello 指纹，而 Windows 端如果未显式指定 `client-fingerprint: chrome`，Mihomo 会采用 Go 默认指纹，直接被目标 Reality 防探测服务器主动丢包。
* **修复机制**：ClashNodeX 导入与更新节点时，**会自动为所有 Reality 节点补齐 `client-fingerprint: chrome`**，彻底根治这一隐蔽故障！

### 5. ⭐ 极致丝滑的节点调序与置顶 (0ms 响应)
* 支持单节点【⭐ 置顶】、【⬆ 上移】、【⬇ 下移】；
* 快捷键操作：选中节点按 **`Alt + ↑`** 或 **`Alt + ↓`** 快速上下调序；
* 毫秒级后台异步防抖落盘，界面操作始终保持 60FPS 丝滑不卡顿。

### 6. 📁 代理组全生命周期管理 & 上下顺序 100% 同步
* **父级联动排序**：在 ClashNodeX 中调整分组顺序后，会自动深度维护顶级策略组（如【节点选择】/【PROXY】）内部对各代理组引用的相对顺序，**保证在 Clash Verge Rev 主界面中的代理组卡片上下排列顺序完全一致**！
* **新建分组安全兜底**：独创安全占位机制，新分组自动通过 Mihomo 内核语法校验，杜绝因分组暂无节点引发的核心报错。

### 7. ✏️ 节点属性完整编辑与重命名 (`F2` / 双击)
* 选中节点按 **`F2`** 或双击节点，直接修改节点名称、服务器域名/IP、端口、UUID 或密钥；
* **弹窗内测速**：在编辑窗口内可选择测速模式，一键点击验证新填写的服务器与端口是否可用；
* **全局级联同步**：重命名节点时，自动同步更新所有分组（`proxy-groups`）和分流规则（`rules`）中的该节点名称，绝不断链。

### 8. 🛡️ 双层防断网沙盒保护（永不断网承诺）
每次写盘前均强制执行两道防线：
1. **0.01ms 内存拓扑语义校验**：验证所有规则引用的目标实体是否存在，拦截孤儿引用；
2. **Mihomo 独立沙盒验证**（`verge-mihomo.exe -t`）：在隔离的临时沙盒环境中试运行；
* **检测到任何风险立即拦截回滚并生成备份**，绝不破坏你原本正常的网络环境！

### 9. 🎨 原生三套经典主题 + 图片壁纸换肤（极致自适应）
* **内置经典三大纯色主题**：
  * ⚪ **经典浅白 (Default Light - 默认)**：现代浅灰白，极致清爽，办公与白昼首选；
  * 🌙 **极客黑夜 (Dark Night)**：沉浸式深邃黑蓝，夜间极客护眼；
  * ❄️ **现代冷灰 (Nord Slate)**：冷灰蓝与 GitHub 雅致风，柔和高级；
* **🖼️ 图片皮肤/壁纸自由导入**：
  * 支持将任意常见图片格式（`*.png`, `*.jpg`, `*.jpeg`, `*.webp`, `*.bmp`）一键设置为皮肤背景；
  * **智能色彩算法**：程序内置图像分析算法，自动识别壁纸明暗与氛围色调，自适应匹配界面文字与按钮对比度，既美观又清晰易读；
  * **自带精美渐变壁纸示例**：在【皮肤】菜单中点击【🎨 应用示例图片壁纸】即可体验；随时点击【🗑️ 清除图片壁纸】瞬间无缝恢复经典浅白纯色；
  * 支持自定义 JSON 皮肤配置导入导出。

### 10. 🔠 界面字体多档无级缩放
* 针对视力不佳、大屏高分屏（2K/4K）或距离较远的场景，顶部工具栏提供 **`[A-]` `[100%]` `[A+]`** 调节按钮；
* 支持在 80% ~ 180% 之间一键平滑放大或缩小所有按钮、列表、文字，自动记忆偏好，彻底告别文字拥挤或看不清。

### 11. 🖥️ 现代质感交互与细节打磨
* **macOS 风格右键圆角菜单**：带智能屏幕防越界算法，彻底解决弹窗飞出屏幕的尴尬；
* **统一按键规范**：所有弹窗严格遵循 **“确定/保存键在左，取消键在右”** 的人机工程学规范；
* **极度显眼的保存按钮**：绿色【💾 立即保存 (Ctrl+S)】常驻工具栏最右侧，无论如何缩放窗口绝不被挤出视野；
* **零隐私泄露**：全自动动态探测 Clash 路径，代码中不含任何作者个人隐私路径。

## 🚀 快速上手

### 方式 A：绿色免安装单文件版（推荐普通用户）
1. 前往 GitHub **[Releases](../../releases)** 下载最新的 `ClashNodeX.exe`；
2. 双击直接运行（绿色独立单文件，无需安装 Python 或任何运行库）；
3. 确保你的 Clash Verge Rev 处于开启状态，软件将自动识别当前配置 Profile；
4. 自由增删改、测延迟、调顺序，享受飞一般的体验！

### 方式 B：从源码运行（开发者与极客）
```bash
# 1. 克隆代码仓库
git clone https://github.com/<your-username>/clash-node-manager.git
cd clash-node-manager

# 2. 安装依赖 (仅需 pyyaml, pillow, opencv-python)
pip install -r requirements.txt

# 3. 启动管理工具
python gui.pyw
```

## ⌨️ 常用快捷键一览

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Ctrl + V`** | 从剪贴板导入节点链接、订阅链接或识别剪贴板二维码截图 |

| **`Alt + ↓`** | 下移当前选中的节点 |
| **`Ctrl + ↑`** | 上移当前选中的分组 |
| **`Ctrl + ↓`** | 下移当前选中的分组 |
| **`Delete`** | 从当前分组中移除选中的节点 |
| **`Ctrl + S`** | 手动触发异步安全保存与内核热重载 |
| **`F5`** | 重新从磁盘加载当前 Profile 配置 |
